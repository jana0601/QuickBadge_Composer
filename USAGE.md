# Quick Usage

1. Run `python -m app.main`.
2. Select a template file (`.png/.jpg/.jpeg/.pdf`).
3. Click `QR`, `Name`, or `Logo` target mode and click on the preview to set anchor positions.
4. Set sizes and output folder. Optional: select `Name font file` (`.ttf/.otf`) for better text control.
5. Save profile JSON so you can reuse coordinates later.

## Single Mode

1. Fill `Person name` and `Coupon code`.
2. Click `Generate Single`.

## Batch Mode

1. Prepare CSV with columns:
   - `person_name`
   - `coupon_code`
2. Select CSV file.
3. Click `Generate Batch`.
4. Track progress; you can cancel mid-run.
